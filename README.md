# Pos_Tech_DTAT

Aqui você encontra todos os códigos utilizados em aulas nas disciplinas da Pós Tech em Data Analytics.

## Instalação por fase

Crie ou ative o ambiente virtual na raiz do projeto e instale as dependências
da fase desejada:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r ".\Fase 1\requirements.txt"
python -m pip install -r ".\Fase 2\requirements.txt"
python -m pip install -r ".\Fase 3\requirements.txt"
python -m pip install -r ".\Fase 4\requirements.txt"
python -m pip install -r ".\Fase 5\requirements.txt"
```

As aplicações Docker da Fase 4 mantêm requirements próprios dentro de cada
serviço (`api`, `train` e `streamlit`).
